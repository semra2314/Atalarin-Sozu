# Widgy - Wordmark + widget motif (modern, super basic)

Brand: warm off-white `#FDF8F8`, coral accent `#d44a33`, ink `#1D1D1F`.
Concept: the word "widgy" with a small widget tile baked into it. Legible, minimal, modern.

Note: a full wordmark gets tiny on a 60x60 home-screen icon. Prompt 1 and 2 are best as
**logo / branding** (App Store, header, splash). Prompt 3 is the **icon-safe** version.

---

## Prompt 1 - Wordmark, dot-as-widget (recommended)

```
A flat vector logo wordmark on a warm off-white (#FDF8F8) background, 1024x1024, square, no transparency, no rounded corners on the canvas. The word "widgy" in lowercase, set in a clean modern geometric sans-serif, bold weight, in ink (#1D1D1F), centered. The tittle (the dot above the letter "i") is replaced by a small rounded-square widget tile in coral (#d44a33). Lots of negative space, minimal, confident, premium. Flat solid colors only, no gradients, no shadows, no outline. Crisp edges.
```

## Prompt 2 - Wordmark with a bento cluster

```
A flat vector logo on a warm off-white (#FDF8F8) background, 1024x1024, square, no transparency. The lowercase word "widgy" in a modern bold geometric sans-serif, ink (#1D1D1F), centered in the lower half. Above it, a tiny minimal "bento" cluster of three rounded-square tiles (two ink, one coral #d44a33) suggesting home-screen widgets. Balanced, airy, super minimal. Flat solid colors, no gradients, no shadows, no extra text. Sharp vector edges.
```

## Prompt 3 - Icon-safe (rounded app-icon tile)

```
A flat iOS app icon, 1024x1024, square, full-bleed, no transparency, no pre-rounded corners. Background is a warm off-white (#FDF8F8). Centered: the lowercase word "widgy" in a bold modern geometric sans-serif, ink (#1D1D1F), sized large but within a 20% safe margin, on a single line. The dot of the "i" is a small coral (#d44a33) rounded-square widget tile. Nothing else. Flat solid colors only, no gradients, no shadows. Must stay readable when scaled down.
```

---

## Tips
- Ask for "single line, one word, lowercase, no other text" so it doesn't invent a tagline.
- If the "i" dot idea gets lost, add: "make the coral square clearly a small rounded square, slightly larger than a normal dot."
- Good typeface hints if you want to steer it: "geometric grotesque like a rounded Futura / Poppins feel."
- Keep the 1024 master. For the app icon, prefer Prompt 3; use Prompt 1 or 2 for the App Store and in-app branding.
