# Widgy - iOS App Icon Prompts (3 styles)

Brand: warm off-white `#FDF8F8`, single coral accent `#d44a33`, ink `#1D1D1F`, Fraunces serif.
Paste any block below into ChatGPT (image generation). Pick the winner, then export at 1024x1024.

**Shared iOS rules (already in each prompt):** 1024x1024 px, square, full-bleed background, NO transparency, NO rounded corners (iOS masks them), NO drop shadow, keep the mark centered with ~15% safe margin, must stay legible at 60x60.

---

## Style 1 - Editorial serif monogram

```
A flat iOS app icon, 1024x1024, square, full-bleed with no rounded corners and no transparency. Background is a warm off-white (#FDF8F8). Centered: a single lowercase letter "w" as a refined serif monogram in the Fraunces typeface, heavy weight, with soft rounded terminals, in coral (#d44a33). The letter is large but sits inside a ~15% safe margin. Minimal, premium, editorial App Store aesthetic. No gradients, no shadows, no extra text, flat solid colors only. Must read clearly at small sizes.
```

## Style 2 - Bento widget mark

```
A flat iOS app icon, 1024x1024, square, full-bleed with no rounded corners and no transparency. Background is a warm off-white (#FDF8F8). Centered: an abstract "bento grid" mark made of a few rounded-square tiles arranged like home-screen widgets, one large tile plus two smaller tiles. The tiles are ink (#1D1D1F) except one accent tile in coral (#d44a33). Generous spacing between tiles, ~18% safe margin. Clean, geometric, modern iOS utility feel. Flat solid colors, no gradients, no shadows, no text. Legible at small sizes.
```

## Style 3 - Coral spotlight

```
A flat iOS app icon, 1024x1024, square, full-bleed with no rounded corners and no transparency. Background is a solid coral (#d44a33). Centered: a single crisp off-white (#FDF8F8) glyph of a rounded square with a smaller square nested in its corner, suggesting a customizable widget. Bold, high-contrast, confident. Thick even strokes, ~15% safe margin. Flat solid colors only, no gradients, no shadows, no text. Instantly recognizable at 60x60.
```

---

## Tips
- Ask ChatGPT for a "flat vector app icon, no photographic texture" if it adds noise.
- Generate a couple of variants per style, then judge them shrunk down to home-screen size.
- Keep the winner's source; you will need the 1024 master for Xcode's AppIcon set (it auto-generates the rest).
- If a style comes out too busy, add "simpler, fewer elements, more negative space" to the prompt.
